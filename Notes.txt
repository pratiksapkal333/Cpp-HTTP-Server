**Event-Driven HTTP Server | C++, Linux, epoll, Socket Programming**

### Description

* Built a high-performance HTTP server from scratch in C++ using Linux TCP socket programming and asynchronous event-driven architecture
* Implemented non-blocking sockets using `fcntl(O_NONBLOCK)` and scalable I/O multiplexing using `epoll` with edge-triggered mode (`EPOLLET`)
* Designed a reactor-style event loop capable of handling multiple concurrent client connections efficiently
* Implemented persistent per-client buffering to correctly handle fragmented TCP packets and partial HTTP requests
* Developed HTTP request parsing including request line extraction, header parsing, `Content-Length` handling, and POST body processing
* Added support for GET and POST methods with modular function-based routing using `unordered_map` and handler dispatch architecture
* Built static file serving for HTML/CSS files with MIME type handling for proper browser rendering
* Managed socket lifecycle, epoll registration/removal, disconnect cleanup, and non-blocking read handling using `EAGAIN/EWOULDBLOCK`
